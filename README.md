One short joke about office life, 200 characters at most. A judge model compares the entries two at a time and the funniest line takes the top places.

> This meeting could have been an email, but the email would have become a meeting, so we compromised and did both.

## Run it

```sh
python3 main.py
```

The program writes the joke to `entry.txt` in the output directory the harness provides (`MAKEFUN_OUTPUT_DIR`, else `/output`).
